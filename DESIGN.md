# Learning Video Vault Design Standard

The interface will use a quiet editorial workspace aesthetic. It will prioritize reading, reflection, and management rather than marketing. The visual system uses off-white and charcoal foundations with one deep indigo accent, a single moderate corner-radius scale, and consistent hierarchy in both light and dark themes.

The design will use shadcn/ui primitives exclusively for interactive and structural UI. The dashboard will favor an asymmetric responsive content layout, real data-driven cards and tables, generous intentional whitespace, and clear page-level navigation. Motion will be limited to short transitions on dialogs, sheets, popovers, and state changes, with a reduced-motion fallback.

The implementation must avoid generic three-card marketing grids, decorative status indicators, image-overlaid pills, artificial dashboard mockups, prominent gradients, and unnecessary borders on every list row. Every state must be purposeful: loading, empty, error, hover, keyboard focus, and destructive confirmation. The dashboard, editor, and entry pages will retain the same color, shape, and theme system throughout.
